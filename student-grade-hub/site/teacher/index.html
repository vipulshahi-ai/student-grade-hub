How these insights are calculated

Participation: Active ≥80% submitted; Intermediate active 50–79.9%; Low active <50%. These are adjustable teaching indicators, not permanent student traits. Performance support bands use the average of submitted marks: ≥80 advanced, 50–79.9 developing, below 50 concept support. Insufficient evidence stays unclassified.

Topic rankings use whole-activity scores mapped to a single topic or mixed-topic group. A multi-topic assignment is never presented as a precise score for each individual topic. Missing records count as zero for overall performance. A recorded zero is still submitted when the backend status says Submitted.

Learning speed cannot be inferred from marks or lateness. Fast / mid / slow learning pace needs comparable repeated attempts and learning timestamps. Until captured, this view reports insufficient timing evidence. Historic timing with no explicit evidence is Unknown.
